# CookieRun: OvenBreak Animation Constructor

A Python script that uses CookieRun: OvenBreak (CROB) assets to produce animations.

## Dependencies

 - [Python >=3.15](https://www.python.org/downloads/): uses [explicit lazy imports](https://peps.python.org/pep-0810/).
   - [Pillow >=9.1](https://pypi.org/project/pillow/): uses the [Transpose enumeration](https://github.com/python-pillow/Pillow/commit/f8e4e9c2dd94c6f4789639dd891b8a6d5fb16e14#diff-4805c79264fea07df59058db82ed74bb2f5c5023e212ac678536a534c56e5be2R143)
 - [ImageMagick](https://imagemagick.org/download/): exact version required unknown. Tested with 7.1.2-34, but much older versions are likely okay.

## Using

You will need to understand how to run a Python script in a command prompt, as this requires it. On Windows, either Command Prompt or Powershell will work.

Exactly how to use the script will be printed when running the script with no arguments. Add `-h`/`--help` for more details.

Note that due to possible updates to CROB, this script might not work on the most recent version.
